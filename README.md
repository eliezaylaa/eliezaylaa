## About

I'm a full-stack engineer based in Paris, finishing my Master's at EPITECH. I've been freelancing since 2021 and I do the whole job myself: talk to the client, pick the stack, build it, ship it.

These days I mostly build apps with AI in them: LLM APIs, RAG, LangChain agents, MCP servers. I like using AI where it saves real time and keeping someone in the loop where it matters.

**Looking for:** an alternance or a 4 to 6 month internship in full-stack or AI engineering, anywhere in France.
